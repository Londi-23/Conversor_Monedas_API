# 🚀 SOBRE EL PROYECTO

¿Necesitas saber cuánto valen tus ahorros en dólares o planeas tu próximo viaje por Latinoamérica? **Vértice Cambio** elimina la complejidad de los mercados financieros y te entrega **resultados exactos en segundos**. 

Diseñada bajo una estética de terminal clásica pero modernizada, nuestra herramienta es la solución definitiva para el usuario que valora la **rapidez y la eficiencia**.

---

# 🛠️ CÓMO FUNCIONA

1.  **Selecciona** tu par de divisas desde el menú principal.
2.  **Ingresa** el monto que deseas convertir.
3.  **¡Listo!** Obtén el resultado con el desglose exacto de la tasa aplicada.
